# 松果CAM Introduction｜用一台拍学机，认识松果CAM

## 一、先看它能做什么

把松果CAM 对准身边的东西，按一下侧面的按键：画面定格，屏幕右侧弹出一张知识卡片，「小松果老师」开口讲解：

> 「这是一只帝企鹅！帝企鹅是体型最大的企鹅，它们生活在寒冷的南极。你注意看它脖子上的羽毛，是不是像戴了一条漂亮的橙黄色围巾？」

孩子可以接着问「企鹅会飞吗？」，它会直接回答；遇到拿不准的，它会联网查，然后说「我查到的是……」。

这就是**拍学机**：OpenBMB 用松果CAM 做的官方案例。它只用到了松果CAM 自带的摄像头、屏幕、麦克风、喇叭和一个按键，不需要接任何额外硬件。

**为什么用拍学机来认识松果CAM？** 因为它刚好把松果CAM 的核心能力串了一遍：

```text
  摄像头 ── 看 ──┐                          ┌── MiniCPM-o 5   看懂照片、听懂提问、开口讲解
  麦克风 ── 听 ──┤                          │
                 ├──── 松果CAM ── 网络 ─────┤
  屏幕   ── 显示 ┤      （拍学机）           ├── 小松果老师      一段提示词，决定它怎么讲
  喇叭   ── 说 ──┤                          │
  按键   ── 拍 ──┘                          └── 工具            联网查询、在屏幕上出卡片
```

- **硬件负责输入和输出**：摄像头、麦克风收集画面和声音；屏幕、喇叭把结果展示出来。
- **模型负责理解和生成**：MiniCPM-o 5 同时会看、会听、会说，还会调用工具。
- **应用负责串起来**：什么时候拍照、给模型看什么、模型要查资料时去查、结果怎么显示。

读完这份介绍，你会知道这三层分别在哪、怎么用、怎么改。

## 二、认识松果CAM：拍学机的眼、耳、口、脸

| 松果CAM 部位 | 在拍学机里的作用 |
|---|---|
| 摄像头 | 拍学机的「眼睛」：取景、按下快门时定格一张照片 |
| 触摸屏（2.4 英寸） | 拍学机的「脸」：显示取景画面、定格照片、知识卡片、字幕 |
| 麦克风 | 拍学机的「耳朵」：听孩子提问 |
| 喇叭 | 拍学机的「嘴巴」：小松果老师说话 |
| 侧面功能键 | 拍学机的「快门」：按一下拍照，再按一下回到取景 |
| Wi-Fi | 连接云端模型；所有理解和生成都在云端完成 |

> 在其他应用里，功能键默认是「返回首页」；拍学机把它改成了快门。应用可以自己决定按键的用途。

**一个关键事实**：松果CAM 不在板子上跑大模型。板子负责采集、显示和播放，模型通过网络在云端运行。所以**必须联网**，而且每一次讲解都是一次网络请求，偶尔会有一两秒的等待。

## 三、上手：三步打开拍学机

1. **开机联网**：用 Type-C 线供电，进入首页后打开 **设置 → WiFi**，扫码配网或手动输入密码。需要网页认证的公司、学校 Wi-Fi 连不上，请改用手机热点。
2. **扫码绑定**：首页打开 **设备绑定**，用手机扫码、登录 OpenBMB 账号确认。板子显示「绑定成功」后，体验额度就到账了，之后重启不用再绑。
3. **打开拍学机**：在首页点 **拍学机** 图标，4 秒左右进入取景画面，右上角显示「在听」就可以开始了。

（详细步骤和截图见《松果CAM 使用手册》第 0 章。）

## 四、玩拍学机：操作说明

**屏幕上有什么**

| 位置 | 内容 |
|---|---|
| 左上 | 「拍学机」和一句提示（取景时：对准想认识的东西，按「拍」） |
| 右上 | 状态章：「在听」= 正常；「点我重连」= 断开了，点一下重连；「退出」回到首页 |
| 中间 | 取景画面 / 定格的照片；右侧是知识卡片 |
| 下方 | 字幕：小松果老师在说什么 |
| 底部 | 三个按钮：「更多」（设置、音量）、「拍」/「再拍一张」、「静音」 |

**怎么玩**

| 你做 | 拍学机做 |
|---|---|
| 对准一样东西，按功能键或点「拍」 | 定格照片，1—3 秒后开口讲：先说是什么，再讲一个好玩的知识，最后问你一个小问题；同时弹出知识卡片 |
| 等它讲完，开口追问 | 直接回答；拿不准的会联网查，屏幕左上显示「正在联网查…」→「查到了 · 来源网站」 |
| 讲解中想换东西 | 再按一下功能键：它马上停下，回到取景 |
| 点「静音」 | 不出声，只出字幕；再点一下恢复 |

**试试这些**

- 拍：一本绘本或课本的封面、一盆植物、一个水果、一个玩具、一件乐器
- 问：「它吃什么？」「它能活多少年？」「为什么会这样？」
- 安全话题：问它「我可以自己玩打火机吗？」，它会提醒危险、请大人帮忙

## 五、拍学机背后：按一下快门，发生了什么

这一节对应松果CAM 的三项核心能力，也是你做自己作品时要用到的三样东西。

```text
 ① 按快门 → 定格一张照片
 ② 照片 + 一句话（"小朋友刚拍了一张新照片，请讲给他听"）发给 MiniCPM-o 5
 ③ 模型看懂照片 → 一边开口讲解，一边调用 show_card 工具 → 屏幕弹出卡片
 ④ 孩子追问 → 模型听懂 → 需要时调用 web_search 工具 → 拿到结果再讲
```

### 1. 模型：MiniCPM-o 5（看、听、说）

- 拍学机全程只用一个模型：MiniCPM-o 5。它是 OpenBMB 的全模态模型，能同时理解画面和声音，并直接用语音回答。
- 它是「全双工」的：边听边想边说，不用等你按「说完了」。
- 松果CAM 上的应用通过**设备凭证**调用模型（第三节绑定后自动生效），代码里不用写任何密钥。

### 2. 提示词：「小松果老师」决定它怎么讲

同一个模型，换一段提示词就是另一个角色。拍学机的提示词规定了：

- **身份**：住在松果CAM 里的小松果老师，陪 3—12 岁的孩子认识世界。
- **讲解步骤**：先说是什么 → 讲一个好玩的知识点 → 问一个引导观察的小问题。
- **说话方式**：句子短、不说术语、只说中文。
- **不确定时**：看不清就说「离近一点再拍一次」；数字、年份和拿不准的事先查再说，不编。
- **安全**：不讲不适合儿童的内容；遇到危险物品先提醒；不打听孩子的姓名、住址。

### 3. 工具（Agent Harness）：让模型能「做事」

模型自己只会说话。要让它在屏幕上出卡片、去网上查资料，就要给它**工具**。拍学机给了它两个：

| 工具 | 什么时候用 | 结果 |
|---|---|---|
| `show_card` | 讲解拍到的东西时 | 屏幕右侧出现卡片：名称 + 2—3 条要点 + 来源 |
| `web_search` | 遇到数字、年份或拿不准的事 | 拿到搜索结果，模型转述成孩子听得懂的话 |

模型自己判断什么时候该用哪个工具，应用负责执行，然后把结果交回给模型。这就是 Agent Harness 的基本思路（详见使用手册第 4 章）。

## 六、改成你自己的作品

拍学机是一个可以直接改的样板。按难度从低到高：

**第 1 级：只改提示词**（不用写代码）

把「小松果老师」换成别的角色，就是一个新应用：

| 把角色改成 | 就得到 |
|---|---|
| 植物图鉴老师：说出植物名字、怎么养、多久浇水 | 植物管家 |
| 英语小老师：说出东西的英文单词，教孩子跟读 | 拍照学英语 |
| 博物馆讲解员：讲文物的年代和故事 | 口袋讲解器 |
| 厨房助手：认出食材，推荐一道家常菜 | 冰箱看菜谱 |

**第 2 级：加一个工具**

比如加一个「收藏到图鉴」工具，把拍过的东西存下来；或者接一个查天气、查百科的接口。工具的写法可以照着 `show_card` 改。

**第 3 级：二次开发**

拍学机的完整源码、部署脚本和真机自动化测试都已开源：
[github.com/TheNight-Watch/paxueji-demo](https://github.com/TheNight-Watch/paxueji-demo)

做好了，打包成应用，投稿**火种计划**（见使用手册第 6 章）。

## 七、使用小贴士

| 情况 | 怎么办 |
|---|---|
| 照片模糊 | 镜头是手动对焦的，拧一下镜头，让 20—40 厘米处最清楚；被拍的东西放在这个距离 |
| 它讲话时我插话没反应 | 为了不让喇叭声被当成提问，它说话时不听；先按一下功能键打断，或者等它说完再问 |
| 旁边有人聊天，它接话了 | 尽量在安静的地方用；它会尽量只回应对它说的话 |
| 右上角变成「点我重连」 | 检查 Wi-Fi，然后点一下状态章 |
| 讲到一半没声音了 | 看看是不是点了「静音」（右下角变成橙色「已静音」） |
